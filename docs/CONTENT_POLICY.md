# Depo içeriği

EON deposunda **yalnızca genel proje bilgileri** yer alır. Kişiye özel bilgi, gerçek iletişim bilgisi, kullanıcı adı, öğrenci numarası, kişisel donanım konfigürasyonu, gerçek klasör yolu, özel sohbet veya gizli anahtar eklenmez.

Örnekler sentetik olmalı. Gerçek kurulumlarda uygulama yolları yalnız kullanıcı bilgisayarının yerel ayarlarına yazılır. GitHub Release açıklamaları ve README de aynı kurala tabidir.

Yayın öncesinde değişiklikler elle incelenir; otomatik gizlilik taraması ek koruma sağlar ancak her bağlamsal kişisel bilgiyi yakalayamaz. Git commit yazarı ve geçmiş Release arşivleri ayrıca değerlendirilmelidir.
