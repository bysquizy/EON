# EON v0.6.1 — Sıfır Kurulum, Donanım Optimizasyonu, Gemini Öncelikli Başlangıç ve Hızlı Ses Denetimi

- **Her Bilgisayarda Otomatik Optimizasyon (`eon/hardware.py`):** Açılışta fiziksel RAM ve CPU çekirdek sayısını yerel olarak algılar (`low`, `balanced`, `high` katmanları); düşük donanımlı bilgisayarlarda bağlam boyutunu ve model bekletme süresini otomatik optimize eder. Başlangıçta `/api/bootstrap` ve uygulama taraması tembel (lazy) yüklenerek milisaniyeler içinde açılır.
- **Google Gemini API Öncelikli & İsteğe Bağlı Ollama:** Ollama kurulumu zorunlu değildir. Kullanıcı doğrudan Ayarlar ekranından Google Gemini API anahtarını (DPAPI şifreli) girerek hemen sohbete başlayabilir. Yerel model kullanmak isteyenler için bilgisayarın RAM kapasitesine uygun Ollama modelleri boyut ve açıklamalarıyla önerilir.
- **Süreç İçi Anlık Bilgisayar Sesi Kısma (`eon/audio.py`):** Windows Core Audio `IAudioEndpointVolume` COM arayüzü üzerinden harici süreç başlatmadan (2–3 ms içinde) üst çubuktan ve Ayarlar'dan bilgisayarın ana ses düzeyini değiştirme ve tek tıkla sessize alma (mute).
- **Python Kurulumu Zorunlu Olmayan Taşınabilir Başlatıcı (`baslat.bat`):** Bilgisayarda Python kurulu değilse `baslat.bat`, resmi `python.org` Windows Embeddable (taşınabilir) paketini otomatik olarak `.python\` klasörüne indirip yapılandırır ve EON'u çalıştırır.
- **Açık Kaynak Gizlilik ve Sıfır Kişisel Veri:** Yerel ses motoru üçüncü taraf sunuculara metin göndermez. Sıkı `Cross-Origin-Opener-Policy` ve `object-src 'none'` başlıkları eklendi; tüm depo kişisel yol ve kimlik verilerinden arındırıldı.
