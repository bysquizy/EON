# EON v0.0.1 — İlk adım

EON'un ilk sürümü burada. Bu, henüz tamamlanmış bir AI asistanı değil; yerel sohbetin ve temel güvenlik sınırlarının denendiği küçük bir başlangıç.

### Bu sürümde

- Ollama üzerinden yerel AI sohbeti.
- Türkçe ve İngilizce yanıt desteği.
- Kısa süreli sohbet hafızası ve geçmişi temizleme.
- `/hesap` ile temel matematik işlemleri.
- Yerel bağlantıyla sınırlı model istemcisi.
- Windows ve Linux'ta başarıyla çalışan 13 otomatik test.

### Henüz olmayanlar

Sesli asistan, grafik arayüz, kalıcı şifreli hafıza ve Windows otomasyonu sonraki sürümlerde geliştirilecek. Hedef Windows bilgisayarında gerçek Ollama sohbeti henüz doğrulanmadı.

### Nasıl çalıştırılır?

Python ve [Ollama](https://ollama.com/download/windows) kurulduktan, yerel çalışma ayarları yapıldıktan sonra:

```powershell
ollama pull qwen3:4b-instruct
py -3 eon.py
```

Ayrıntılı adımlar için [kurulum rehberine](../SETUP_WINDOWS.md) bak.

**İndirme:** Release sayfasındaki **Source code (zip)**. Henüz EXE kurulum dosyası yok.
