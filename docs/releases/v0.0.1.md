# EON Local v0.0.1 — İlk yerel prototip

**Pre-release · Windows 11 hedefli · Tamamen yerel model**

EON'un ilk sürümü, harici AI API'si kullanmayan kişisel asistanın **komut satırı prototipidir**. Tam özellikli agent veya hazır masaüstü uygulaması değildir.

## Yenilikler

- Python CLI ile yerel yazılı sohbet ve Türkçe EON kişiliği.
- `qwen3:4b-instruct` (varsayılan) veya `qwen3:1.7b` desteği.
- Son 6 konuşma turunun RAM'de tutulması; `/temizle` ile silme.
- `/hesap` ile sınırlı, kod yürütmeyen hesaplama.
- Yalnız `127.0.0.1:11434` adresine ve iki izinli Ollama API yoluna bağlantı.
- **13 birim/negatif test**, yerel geliştirme ortamında geçti.
- Ayrıntılı Türkçe README, kurulum, mimari, güvenlik, gizlilik ve roadmap.

## Henüz yok

Sesli konuşma, Hey EON, şifreli kalıcı hafıza, grafik arayüz, dosya/terminal/Windows otomasyonu, gerçek agent onayları, otonom görev yürütme.

**Doğrulama:** Birim testleri gerçek modeli çalıştırmaz. Hedef Windows cihazında gerçek Ollama sohbeti henüz doğrulanmadı.

## Kurulum

1. Python 3.13 (veya 3.10+) ve resmî Ollama'yı kur.
2. `OLLAMA_NO_CLOUD=1`, `OLLAMA_HOST=127.0.0.1:11434` ayarla; Ollama'yı yeniden başlat.
3. `ollama pull qwen3:4b-instruct` çalıştır.
4. Release altındaki GitHub'ın otomatik oluşturduğu **Source code (zip)** arşivini indirip aç.
5. `baslat.bat` veya `py -3 eon.py` ile çalıştır.

Tam yönerge: [Windows kurulum rehberi](../../docs/SETUP_WINDOWS.md).

## Güvenlik

Bulut AI API'si ve ücretli model servisi yoktur. EON kendi kalıcı sohbet veritabanını oluşturmaz. Windows/Ollama günlükleri ayrı risklerdir. Bu sürüm dosya veya terminal komutu çalıştıramaz.
